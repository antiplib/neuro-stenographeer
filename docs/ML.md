# Дообучение и проверка качества

В версии 0.2 использованы готовые Whisper small, pyannote segmentation и TitaNet. Дообучение не выполнялось: размеченных пользовательских данных пока нет.

Сначала соберите небольшой закрытый тест ваших разговоров: исходный файл, точный текст, язык, интервалы речи каждого участника и разметка перебиваний. Отдельно выделите тренировочную и проверочную части по людям и сессиям. Не разносите соседние кадры одной записи случайно между train/test.

Для ASR подготовьте JSONL с полями audio (путь), text, language, session_id. Для диаризации — RTTM либо JSON с audio, start_ms, end_ms, speaker_id; одинаковый speaker_id должен означать одного реального человека во всём обучающем наборе. Текстовые ID результата приложения сами по себе эталоном не являются.

Порядок: измерить WER/DER/RTF готовых моделей → подобрать параметры языка, clustering и границ на validation → при необходимости дообучить Whisper на аудио-текстовых парах, speaker encoder на размеченных голосах → экспортировать и проверить численное соответствие → обновить веса, SHA256 и APK → повторить независимый тест. Простая подстройка порога не является обучением нейросети.

В приложении заменяются пути asr.bin, segmentation.onnx, embedding.onnx. Для ONNX сохраняйте совместимость метаданных с sherpa-onnx; произвольная ONNX-модель не является взаимозаменяемой. Whisper должен быть экспортирован в совместимый ggml формат, LLM — GGUF. Проверяйте конкретный экспорт до упаковки APK.

Обучение выполняется отдельным инструментарием команды; инференс приложения — локально на Android. Скрипт фиктивного обучения на выдуманных примерах не добавлен.
